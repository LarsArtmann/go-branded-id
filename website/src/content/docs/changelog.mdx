## [0.5.1] — 2026-07-28

### Fixed

- Removed accidentally tracked `namer` binary from the repository. Source archives now contain only source code.

## [0.5.0] — 2026-07-28

### Added

- **`cmd/namer` codemod tool**: CLI that scans Go source for brand types missing the `Name()` method and generates suggested stubs. See the [Namer Tool guide](/guides/namer-tool/).
- **Dual JSON v1/v2 support**: The library now works with both `encoding/json` (default) and `encoding/json/v2` (via build tags). No `GOEXPERIMENT` required.
- **Sentinel errors**: All ID operations return wrapped sentinel errors (`ErrUnsupportedType`, `ErrCannotScan`, `ErrInsufficientData`, `ErrMarshal`, `ErrUnmarshal`, `ErrInternal`, `ErrNilReceiver`). Use `errors.Is()` to branch on error category. See the [Error Handling guide](/guides/error-handling/).

### Changed

- JSON serialization split into build-tagged pairs for dual-mode support.
- CI workflows now run build + tests in both v1 and v2 modes.
- `GOEXPERIMENT=jsonv2` is no longer a hard requirement — the library compiles with plain `go build`.

## [0.4.0] — 2026-07-27

### Changed

- Re-tagged release point aligning dependency updates with the tag-based GitHub release workflow.

## [0.3.2] — 2026-07-13

### Fixed

- **CI build failure**: `id_json.go` and `id_sql.go` now support both `encoding/json` (default) and `encoding/json/v2` (via build tags). CI tests both modes.

### Changed

- README performance table corrected with verified benchmark numbers from Go 1.26.4.
- Installation instructions now document the `` prerequisite.
- `CONTRIBUTING.md` rebuilt with accurate Nix-based instructions.

### Added

- `FEATURES.md` — honest feature inventory with code-verified citations.
- `ROADMAP.md` — long-term vision.
- `docs/DOMAIN_LANGUAGE.md` — added `Phantom Type` and `Zero Value` terms.

## [0.3.1] — 2026-06-17

### Changed

- `Format()` writes directly to `fmt.State`'s writer instead of allocating strings — reduces allocations for `%s` and `%v` formatting.

## [0.3.0] — 2026-06-10

### Added

- **Named brands**: optional `Name()` method on brand types enables `"User:abc123"` display strings.
- `BrandName[B]()` for runtime brand introspection.
- `ValidateID`, `ValidateIDWithValue`, `MustValidateID` for brand-aware validation.
- `Ptr()` and `FromPtr()` for optional ID fields.

### Changed

- `String()` now returns `"Brand:value"` for named brands (was value-only for all brands). Serialization unaffected — still uses raw values.

## [0.2.0] — 2026-05-15

### Added

- Full serialization suite: JSON, SQL, Text, Binary, Gob.
- `Compare()` method for ordered types.
- `Or()` for zero-value fallbacks.
- SQL `Scan` type coercion for all driver types.

## [0.1.0] — 2026-04-20

### Added

- `ID[B any, V comparable]` phantom-typed identifier.
- `NewID`, `Get`, `IsZero`, `Reset`, `Equal`.
- Initial extraction from `go-composable-business-types`.
